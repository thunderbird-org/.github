## What Is Thunderbird?

Thunderbird is a free and open-source email client from the Mozilla Foundation, first released back in 2003 and still under active monthly development today. Beyond email, it doubles as a personal information manager — bundling a calendar, contacts, news feed reader, and chat support into one application.

It's maintained by MZLA Technologies Corporation (a Mozilla subsidiary) and ships for **Windows, macOS, Linux, and Android**, with support for 65 languages.

---

## Core Features

- **Multi-Account Email** — connect Gmail, Outlook, iCloud, or any IMAP/POP provider in one unified inbox.
- **Built-In Calendar** — schedule and manage events without a separate app, a feature that's been native since version 78.
- **Smart Spam Filtering** — a Bayesian filter that learns from how you mark junk mail over time, getting more accurate the more you use it.
- **Automatic HTML Sanitizing** — strips potentially dangerous embedded code and blocks remote images by default in suspicious messages, reducing tracking and exploit risk.
- **OpenPGP & S/MIME Encryption** — built-in support for signing and encrypting emails without needing a separate plugin.
- **Extensions/Add-ons** — expand functionality through Mozilla's add-on ecosystem, similar to Firefox extensions.
- **New Account Hub** — a simplified flow for adding new email accounts, introduced in recent releases.
- **Cross-Device Sync (in progress)** — Thunderbird for Android is being developed to sync accounts and settings with the desktop version.
- **RSS/News Feed Reader** — follow websites and newsgroups directly from the same inbox interface.

## Recent Improvements (2026 Releases)

- **Smarter OAuth handling** — account logins now open securely in your default browser instead of an embedded window.
- **Expanded Exchange/EWS support** — better compatibility with Microsoft 365 and on-premise Exchange servers, including calendar and address book sync.
- **Improved crash stability** — fixes for issues that previously caused crashes during header processing or bulk email downloads.
- **Visual PDF signatures** — sign PDF attachments directly within Thunderbird.
- **Unified folder improvements** — account color indicators and tooltips make multi-account inboxes easier to navigate at a glance.

## Release Channels — Which One Should You Use?

| Channel | Best For | Stability |
|---|---|---|
| **Release** | Most users — recommended default | High |
| **ESR (Extended Support Release)** | Users who want fewer feature changes with steady security updates | High |
| **Beta** | Users comfortable testing upcoming features and reporting bugs | Medium |
| **Daily** | Developers/testers only — where new features are actively built | Low |

Unless you have a specific reason to test upcoming features, the **Release** channel is the right choice for everyday use.

## Frequently Asked Questions

**Is Thunderbird really free, with no hidden costs?**
Yes — it's free and open-source with no premium tier, though Mozilla accepts optional donations to fund development.

**Can Thunderbird replace Outlook for Exchange accounts?**
Increasingly, yes. Recent releases have focused heavily on improving Exchange/EWS and Microsoft 365 compatibility, including calendar sync.

**Does Thunderbird sync between desktop and mobile?**
Thunderbird for Android exists as a separate app, with cross-device account sync actively being developed.

**Is my data safe with Thunderbird?**
As an open-source project with no ad-based business model, Thunderbird doesn't monetize your inbox data the way some commercial webmail services do.
